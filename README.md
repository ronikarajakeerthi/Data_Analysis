# 🛒 Online Retail Customer Analysis

This project is an **Online Retail Customer Analysis Dashboard** built using Python, Streamlit, Plotly, and K-Means Clustering.

## Project Overview

The project analyzes online retail transaction data to understand sales performance and customer purchasing behavior.
It provides an interactive Streamlit dashboard with:
* Sales analysis
* Customer analysis
* Product analysis
* Country-wise filtering
* Customer segmentation
* K-Means clustering
* Customer prediction
* Interactive charts
* Automatic analysis report

## Technologies Used
* Python
* Pandas
* Streamlit
* Plotly
* Scikit-learn
* K-Means Clustering

## Features
* Total Sales
* Total Customers
* Total Orders
* Total Quantity
* Average Order Value
* Monthly Sales Analysis
* Top 10 Products
* Country Filter
* Customer Segmentation
* Customer Prediction
* Business Insights and Recommendations

##  Machine Learning
K-Means Clustering is used to segment customers based on:
* Total Spending
* Total Quantity
* Number of Orders
